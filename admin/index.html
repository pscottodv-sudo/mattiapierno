Come creo il token (una volta sola)
  1. Apri github.com/settings/personal-access-tokens/new
  2. Nome: "Pannello sito". Scadenza: quella che preferisci.
  3. Repository access: Only select repositories → il repository del sito.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, copialo e incollalo qui sopra.
